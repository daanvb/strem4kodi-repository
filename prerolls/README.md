# Audio pre-rolls

Upload each video into the folder matching its actual audio format. Keep the original video and audio tracks.

| Folder | Audio format |
| --- | --- |
| [dolby-atmos](dolby-atmos/) | Dolby Atmos |
| [dolby-truehd](dolby-truehd/) | Dolby TrueHD |
| [dolby-digital-plus](dolby-digital-plus/) | Dolby Digital Plus / E-AC-3 |
| [dolby-digital](dolby-digital/) | Dolby Digital / AC-3 |

Use descriptive filenames and retain the original extension, for example `dolby-atmos-amaze.mkv`.

These folders only organise the media. Configurable pre-roll playback and local downloading have not been implemented yet.
