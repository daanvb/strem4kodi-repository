# Strem4Kodi 1.8.67

Search and Discover gain genre and public MDBList browsing, with paging and
Back-position restoration across refreshed grids and collections. Playback
adds chapter and media controls, remembered audio/subtitle selection, forced
subtitle precedence, and unpause rewind. Up Next and automatic source retries
better respect cancellation, session ownership and source preflight results.

Diagnostics remain opt-in and send bounded summaries only to the configured
private GitHub repository. Token and opt-out state are checked immediately
before upload. Home remains available when its optional Continue Watching
SQLite index is locked, read-only or unavailable. Index writes support older
Android SQLite, and foreground/background row changes are serialized with
stale-result checks.

The pre-release working tree passed 1,288 automated tests. Release package,
source agreement, credential-signature and feed checks are required before
publication. Kodi Shield playback, remote navigation, subtitle selection,
SQLite behavior and display switching still need device confirmation.

Player skin remains 0.1.19. Restart Kodi after updating.
