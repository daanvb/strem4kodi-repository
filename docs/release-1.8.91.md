# Strem4Kodi 1.8.91

Search suggestions and full-result titles now use the app shell to open details and restore the exact originating screen. Selection/redraw/closure are coordinated, closed controls reject late background updates, and the next window waits for Kodi's closing transition.

Up Next restores the parent series ID and show name from the episode playback handoff before refreshing metadata. Its card displays the next episode's title and number rather than repeating the currently playing episode as the series name.

Chart membership is cached independently of Home. AIOMetadata artwork can display native poster tags on the shared image host. Current ranks, explicit series status and director facts take precedence over lifetime awards; the centred boxes now have rounded corners.

Private diagnostics gain persistent interrupted-session markers, UI stages before window allocation, installed-file fingerprints, focused error categories and aggregate poster-tag counts. Troubleshooting includes Send diagnostic report now, using the existing opt-in and private sync token. These fields exclude search text, titles, URLs, raw errors, paths and credentials.

All 1,570 automated tests passed before release metadata changes. Package/source and feed checks are required before publication. Player skin remains 0.1.23 and repository installer remains 1.0.4. Restart Kodi after updating. Native Fire TV crash resolution requires device confirmation.
