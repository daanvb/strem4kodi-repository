# Strem4Kodi 1.8.68

Settings now have a visible Details button: press Right from a setting and OK
for its complete explanation. Back retains the selected setting.

Sports opens with Football, followed by Live Now and the remaining lists
alphabetically. One list selector replaces the redundant type/family filters.
Selecting an event opens its source picker directly; cancelling returns to
Sports without the intermediate Choose source/More page or recommendations.

Owned live streams use the animated companion player, stream details, audio
and subtitle pickers, and the existing player timeout. Chapters and watched
progress are excluded. Live delay is explicitly unavailable without verified
broadcast timing. Playback settings offer access to Kodi Services caching;
cache values are not changed automatically.

Player skin updates to 0.1.20. Restart Kodi after updating. Automated regression
checks passed; actual Shield sports playback and remote navigation still need
device confirmation.
