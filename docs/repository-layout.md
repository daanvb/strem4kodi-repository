# Repository layout and maintenance

## Private source

`daanvb/freeBird-private` uses `firebird` for active independent development. Historical branches are retained by default; original `main` and `kodi-repository` remain preserved. With explicit user approval, merged task branches may be removed after verifying their current tips are ancestors of `firebird`, excluding protected branches and open PR heads. Use expected-tip checks so concurrent branch changes reject deletion. Do not rewrite history. The repository stays private. Tests and public-source safety checks run on every push.

The original automatic publisher targeted the old `main` / `kodi-repository` branch pair. Its workflow is preserved under `docs/legacy/repository-workflow.yml` in the source checkout for reference; it is no longer an active release trigger. The supported publication route builds and verifies packages locally, passes GitHub validation, then publishes to the separate public feed.

## Installations and retired identities

Current packages use `script.freebird`, `skin.freebird` and `repository.freebird`.
The 6 November repository cleanup removes legacy Strem4Kodi entries, package
folders and installer aliases from the active feed and website. Historical
recovery files remain in Git history; no history is rewritten. Installed legacy
addons are not uninstalled remotely.

Migration removal is prepared in PR #260 and must be integrated before publishing
the next fresh-install-only app. The cleanup itself keeps app 1.8.241 and player
0.1.48 unchanged, including their existing runtime behavior.

## Public feed

`daanvb/freeBird-repository` uses `main` for GitHub Pages:

- `addons.xml` and `addons.xml.sha256`: Kodi's update index and checksum.
- `script.freebird/`: current app and declared artwork.
- `skin.freebird/`: current player skin and artwork.
- `repository.freebird/`: current repository installer and artwork.
- Legacy package directories are retired; use Git history for historical recovery.
- `repository.freebird.zip` is the sole root installer download.
- `index.html`: installation page generated by the source feed builder.
- `repository.freebird.zip`: stable current installer for Kodi's TV file browser.
- Package-directory `index.html` pages: filename-matching links that Kodi can browse
  without JavaScript, including retained rollback versions when staged.
- `docs/`: configuration, discovery and feature guides; previous release highlights live here instead of filling the README.
- `prerolls/`: upload guidance. Video files are release assets under **Audio Pre-Rolls**, outside the Pages tree.

Keep current plus previous versions in each package directory. Retain any additional skin version required by the retained app packages. Remove duplicate root app/skin ZIPs and obsolete packages only after download links and the feed have been checked. Do not rewrite Git history. Historical downloads are recoverable by browsing the repository at an older commit or restoring the corresponding tracked file from that commit.

The cleanup does not touch pre-roll assets, private device-sync data, account credentials or source branches. Git history still consumes storage; this retention policy reduces the deployed Pages site and visible clutter, not historical repository size.

The freeBird rename retired the old GitHub Pages address. Existing repository 1.0.4 installers point to that address and cannot discover an update there; install repository 1.0.6 once from `https://daanvb.github.io/freeBird-repository/`. Old installer aliases have been retired. Reinstalling over retained addon data does not reset it.
