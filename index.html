Strem4Kodi

Your Stremio library, built for the Kodi remote. Independently maintained by daanvb.

Install and update

Latest app: 1.8.60. Requires Kodi 21 or later.

Install Kodi repository

In Kodi, choose Add-ons → Install from zip file and select the repository ZIP. Then choose Install from repository → Strem4Kodi Repository → Program add-ons → Strem4Kodi.

The repository installs the required player skin automatically. Restart Kodi after updating both packages.

Manual downloads

Install the player skin ZIP first, then the app ZIP over your existing installation. Restart Kodi afterwards.
