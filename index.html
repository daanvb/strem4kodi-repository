freeBird

Your Stremio library, built for the Kodi remote. Independently maintained by daanvb.

Install and update

Already using Strem4Kodi? The old download address has retired. Install the repository ZIP below once (version 1.0.5 or later) to reconnect automatic updates. Your existing addon, library and saved settings are preserved.

Latest app: 1.8.232. Requires Kodi 21 or later.

On a TV, open Settings → File manager → Add source and enter:

https://daanvb.github.io/freeBird-repository/

Enable Settings → System → Add-ons → Unknown sources, then choose Add-ons → Install from zip file, open that source and select repository.strem4kodi.zip.

Install Kodi repository

In Kodi, choose Add-ons → Install from zip file and select the repository ZIP. Then choose Install from repository → freeBird Repository → Program add-ons → freeBird.

The repository installs the required player skin automatically. Restart Kodi after updating both packages.

Manual downloads

Install the player skin ZIP first, then the app ZIP over your existing installation. Restart Kodi afterwards.
