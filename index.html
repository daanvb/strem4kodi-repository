Strem4Kodi

Your Stremio library, built for the Kodi remote. Independently developed and maintained by daanvb.

Cinematic browsing, configurable automatic playback, clear stream information, shared watch progress and IntroDB skip controls.

Install and update

Latest app: 1.8.46

Install Kodi repository Download app 1.8.46

In Kodi, choose Add-ons → Install from zip file and select the repository ZIP. Then choose Install from repository → Strem4Kodi Repository → Program add-ons → Strem4Kodi.

Requires Kodi 21 or later. Updating from the repository installs the Strem4Kodi Player skin automatically. Restart Kodi after updating, then select it under Strem4Kodi Settings > Appearance > Player appearance to use the new playback graphics.

Download Player skin 0.1.14

For manual ZIP updates, install the Player skin ZIP first, then the app ZIP over your existing installation. Restart Kodi afterwards.
